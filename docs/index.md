# OpenLawFirm

Open-source practice management for law firms with 1–50 attorneys, built on the [Open Scaffold Labs](https://openscaffoldlabs.com) shared infrastructure. One PostgreSQL database. One React component library. One adapter layer. No integration tax.

## Documentation

- [**OpenLawFirm Connector for Claude**](./connector/) — Drive your firm's practice management from Claude's chat interface, Word, or Outlook. Search matters, log time, query trust balances, find documents.

## Status

OpenLawFirm is in early development. The schema, API surface, and React shell are in place. Core compliance workflows (three-way IOLTA reconciliation, LEDES export, jurisdiction-aware deadlines) are being hardened.

**v1.0 targeted end of 2026.** See [IMPLEMENTATION.md](https://github.com/Open-Scaffold-Labs/OpenLawFirm/blob/main/IMPLEMENTATION.md) for the roadmap.
